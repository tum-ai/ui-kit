# ui-verify

Build Storybook and inspect affected stories at 320, 390, 768 and 1440 pixels. Exercise keyboard navigation, open overlays, focus return, reduced motion, long content and fallback media. Run browser axe and Playwright. Inspect screenshots before accepting updated baselines. Confirm package CSS and assets in the tarball consumer. Record VoiceOver, zoom/reflow, forced-colors and real-iPhone Safari review separately; never claim an unrun check passed. Browser workarounds are documented in docs/browser-quirks.md.
