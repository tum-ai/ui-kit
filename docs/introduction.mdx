# TUM.ai UI kit

A shared visual language for TUM.ai projects: precise typography, calm reading bands, and accessible interactions.

Start with **Foundations**, explore the component families, then compose the shell and page patterns. Controls show supported variants; the Accessibility panel reports automated checks. Passing automation does not replace keyboard, VoiceOver or real-device review.

## Design contract

Use Manrope, semantic tone tokens and supplied marks. Choose HTML heading levels independently of visual size. Base UI supplies interactive behavior. Keep visible focus, announce external links, respect reduced motion and render meaningful content without JavaScript.

## For maintainers

Components, tests, stories and TSDoc change together. The published package and isolated Next consumer are checked in CI. Source provenance, release instructions and manual verification checklists live in the repository documentation. Figma metadata is prepared for a later generated library.
