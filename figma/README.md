# Native scene and reconciliation engine

`schema.mjs` is the versioned JSON scene contract and pre-write validator. `compiler.mjs` validates stable external identities, prepares bounded foundation/page batches and embeds the plain Plugin API runtime for an initial MCP execution. `runtime.mjs` is shared with the [native release plugin](plugin/README.md), which applies release JSON without Codex.

A scene has `schemaVersion: 1`, a package name, `{version, commit}` release identity, collections, variables, text/effect styles, pages and diagnostics. Every native asset and component property has one globally unique stable `key`. Collections have named modes; variables refer to a collection key and use mode-keyed values or `{alias: variableKey}`. Scopes are explicit and WEB code syntax uses `var(--token)`. Unknown native fields, missing references, cyclic aliases, unsupported paints, invalid Auto Layout sizing contexts and error diagnostics are rejected.

Supported scene node types are FRAME, COMPONENT, COMPONENT_SET, TEXT, RECTANGLE, ELLIPSE and SVG. SVG is imported into editable native vectors. IMAGE paints contain inline bytes and MIME type; they represent source imagery, never a screenshot substitute for an unsupported component. Containers can specify Auto Layout and children may explicitly use absolute geometry when the source relationship cannot be represented by that layout. Rich text remains one editable text layer with character ranges. `source` retains capture/token provenance and is excluded from native change hashes.

The ledger is separate from source. It records exact Figma IDs, source hashes, native fingerprints, component-property IDs, variable mode IDs and SVG descendant ownership. `compileBatch(scene, ledger, {fileKey, batchKey})` returns a checked-in-engine script; `batchKeys(scene)` gives the required sequential order. Persist `mergeLedgerPatch(ledger, result.ledgerPatch)` after every response, even a partial failure. Never blindly retry a transport error with unknown canvas outcome. MCP scripts switch page context at most once and return all created, changed and removed canvas IDs.

For a native session, prepare the immutable scene once with `prepareScene(scene)` and compile with `{transport: "native", prepared}`; apply `.payload` directly with `reconcileBatch(figma, payload, sha256)`. No remote code is evaluated. MCP response budgets apply only to the MCP script transport. `planDeprecations(scene, ledger)` reports identities missing from source without removing assets.

Components and text layers update in place; explicit source wrapper changes can reparent a node only while its recorded owned parent and ancestry still match the canvas. Type changes and missing known nodes require an explicit migration. Name collisions never authorize adopting or deleting designer content. Top-level canvas placement is retained. An altered imported SVG keeps its root ID but replaces its exact known vector descendants; these internal vector IDs are not a stable public API. Removed source assets are retained as deprecations. Global child-order migrations and CSS behavior outside the capture contract must be expressed explicitly in the source scene and validated with real Figma evidence.
